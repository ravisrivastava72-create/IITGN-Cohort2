# Which letters name the line that moved each reading, and the window Uber's page carries?

Answers: 1a 2c 3a

*The register and the scholarship are invented for chapter 4, with every number in them. Uber's case is illustrative: the company is real, the situation and the data are synthetic, built for this class.*

One student's 60-day term (invented) holds 10 holidays, 40 days present, 8 absent and 2 on medical
leave. The same register reads 80.0, 66.7, 83.3, 84.0 or 70.0 percent depending on which line
changes. The set asks which line moved a reading, what a scholarship's rule prints, and which window
Uber's before and after comparison needs.

## What does the set test about the four lines?

A number is computable only when its numerator, denominator, window and exclusions are written down,
and each line, changed alone, moves the number. Two honest people disagree because one line differs,
so the fix is to find the line and print the definition beside the number.

## Why is each key right, and why does each other option fail?

| Item | Key | The question in one line | Why the key holds | Why each other option fails |
|---|---|---|---|---|
| 1 | a | Which line differs between 80.0 and 84.0? | Both divide by the 50 working days; 84.0 also counts the 2 medical days as present on top, 42 over 50. | b: both divide by the same 50 working days. c: both read the whole term. d: neither leaves a status out of both counts; the 2 medical days stay in both denominators. |
| 2 | c | What does the certificate print under the scholarship's rule? | Medical leave out of both counts leaves 40 present over 48 days, 83.3 percent, above 75, so the student qualifies. | a: 80.0 is the school's own rule, which keeps the medical days in the denominator. b: 66.7 divides by calendar days. d: 70.0 reads only the last 20 working days, a window the rule does not ask for. |
| 3 | a | Which window should Uber's page carry? | Six whole weeks on each side of the launch hold every weekday's peak windows equally often, so neither side is lifted by a busier day of the week, and six weeks are long enough for a level to show it held. | b: one day each side lets one weekday or one rainy evening decide the comparison. c: one window over the year so far holds both sides at once, so it cannot set before against after. d: two single weeks far apart carry the season along with the scheme. |

## Which item is worth arguing about?

Item 3, and the fact that would switch it. Six weeks a side is the call while the twelve weeks are
ordinary. A festival week inside one side, or the monsoon's end, which the ticket names as a caveat,
would change it: the page would then read the comparison with and without that week, date the
exclusion it keeps, and print it beside the number.

## Where does a written definition show up at work?

Swiggy's shareholder letters define its monthly transacting users as unique users with at least one
completed order in the month, averaged over the period; in the quarter to 30 September 2024 it
reported 17.1 million of them and a platform frequency of 4.53 orders per user a month (Swiggy's Q2
FY25 shareholder letter, filed with BSE, checked 13 October 2026). Because "completed order" and
"averaged over the period" are written down, no reader can mistake the count for registered users.
